# MediMove

Expo/React Native client for requesting and tracking emergency medical transport.
It talks to the MediMove Express backend and uses a shared design system with a
dark-first, calm clinical teal palette (light mode is supported).

## Setup

```bash
npm install
cp .env.example .env
```

Set `EXPO_PUBLIC_API_BASE_URL` in `.env` to your backend URL, **including the
`/api` prefix**. The app does not call a `/health` endpoint.

Then start Expo:

```bash
npx expo start
```

## Checks

```bash
npx tsc --noEmit   # typecheck
npx expo lint      # lint (ESLint flat config)
npx expo-doctor    # dependency/config diagnostics
```

## Project layout

- `src/app/` — Expo Router screens. `src/app/(tabs)/` is the signed-in area;
  `src/app/(auth)/` handles login/registration/verification; `src/app/booking/`
  contains checkout and live tracking.
- `src/components/ui/` — the reusable UI kit (`Button`, `Card`, `Screen`,
  `TextField`, `Badge`, skeletons, etc.). Prefer these over raw RN primitives.
- `src/theme/` — design tokens and `useAppTheme()`. No hard-coded colours.
- `src/services/` — the typed API layer. `api.ts` owns auth headers, single-flight
  token rotation and error normalization; the `*Service` files wrap endpoints.
- `src/store/authStore.ts` — session state. Access/refresh tokens live in
  `expo-secure-store` via `tokenStorage.ts`.
- `src/types/` — backend serializer shapes. Money is always integer **kobo**.
- `src/utils/format.ts` — display formatting for money, dates, status and ETA.

## Runtime notes

- **Location:** `expo-location` is configured in `app.json`. If the user denies
  permission or no GPS fix is available, Dispatch falls back to Ado-Ekiti and
  shows a notice.
- **Tracking map:** the current map is a lightweight schematic projection of real
  lat/lng values. It works in Expo Go, on device and on web. No Mapbox token is
  required. A real tile map can be layered in later with a development build.
- **Payments:** `react-native-webview` is a native module. Card/bank checkout
  therefore requires a development build (`npx expo run:android` / `run:ios`,
  or an EAS development build); it will not work inside Expo Go. Wallet payment,
  booking, tracking and the rest of the app work in Expo Go.

## Native projects

`ios/` and `android/` are generated by Continuous Native Generation and are
git-ignored. Configure native behavior in `app.json` and config plugins, not by
editing those folders.
